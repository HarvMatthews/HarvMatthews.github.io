Statistics Report Generator (Personal Project)

Report Generator that will allow the User to upload downloaded JSON data from Snpchat, Instagram and ChatGPT, generating interesting Statistics as PDF report.
Will be hosted on a webisite, Allowing JSON data to be uploaded producing the PDF with statistics as:

  • Most Used words
  • Messages Sent
  • Top Friends
  • Amount of times certain words have been said on ChatGPT
